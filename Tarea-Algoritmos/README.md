# Excel JS

Proyecto realizado para la materia de Algoritmos.

## Descripción

Este proyecto consiste en una hoja de cálculo sencilla creada con HTML, CSS y JavaScript.

La aplicación permite seleccionar celdas, escribir valores, usar una barra de fórmula, realizar operaciones matemáticas básicas y limpiar toda la hoja.

## Funcionalidades

- Selección de celdas.
- Identificación de celdas como A1, B2, C3, etc.
- Edición directa de las celdas.
- Edición desde la barra de fórmula.
- Operaciones matemáticas utilizando el signo =.
- Botón para limpiar toda la hoja.
- Hoja de cálculo con 5 columnas y 10 filas.

## Ejemplos de operaciones

```text
=5+5
=20-10
=4*5
=100/4
```

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
